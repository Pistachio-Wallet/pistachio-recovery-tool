# Pistachio recovery tool

A standalone, offline-capable page to reach your funds using only your backup —
no Pistachio account, app, or servers required. Paste a private key, Pistachio
recovery phrase, or standard BIP-39 seed; it recomputes your account addresses,
scans balances across chains, and lets you sweep to an address you choose.

Implementation lands via pull request. Licensed under MIT.
